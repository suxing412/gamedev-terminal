# 内核

这个系统认为世界是什么形状，以及这些形状落在盘上哪里。路径解算、写闸、配置、事件流、锁、时钟。

- **可依赖**：（不依赖任何层）
- **禁**：net · process.argv 业务分支 · 裸 Date.now()
- **已建 6 · 待建 1**

## 已建

- `路径.js` —— 解算运行形态下的仓根与数据区：源码态与 portable exe 态已走，部署态留了口没走（形态() 只分前两种）。portable exe 里 __dirname 与 execPath 都是临时解压目录，取路径必须走 PORTABLE_EXECUTABLE_*。
- `写闸.js` —— 全仓唯一 fs 写入口。令牌制：没令牌写数据区直接 throw。白名单不是黑名单——漏了是写不了而不是能写，状态机加新态时默认拦住。
- `证据.js` —— 证据包：一次执行产出的日志、指标、截图、耗时按单号归档成一个可校验的包。旧仓只有 --tag 归属标记，没有包结构，所以「验收看什么」每次都靠人翻。 **它同时是多 harness 适配器的出方契约**——每家交回的都得是这个形状。 **改动清单四家都不原生输出**（调研实证），由适配器 git diff 自算——这是证据包里唯一不能从 harness 拿的一项。
- `时钟.js` —— 可注入的时钟：真钟只在这里读系统时间；假钟不拨不走、拨了才走。领域层不碰真时间，收一个 现在 或一个钟。裸 Date.now() 会让一整片逻辑变异不动。
- `事件流.js` —— 只追加的事件流：只导出 记（写走写闸令牌与追加）、更正（追加一条指着原来那条）、读（一行一 JSON，坏行报出来不炸）。不导出 写。历史不删不改。
- `锁.js` —— 单飞锁（进程内同名的活不叠）与文件锁（wx 独占、记 pid 与时刻、按钟过期才抢、读不出来当活锁不抢）。取单器的拍、Unity 编辑器单实例、文稿并发写都靠它。
