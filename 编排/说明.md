# 编排

会卡死的那一层：取单器、巡检、引擎通道、模型会话、上下文装配。唯一允许长跑的层，因此每处外呼必须有超时与单飞锁。

- **可依赖**：内核 · 领域
- **禁**：（无）
- **已建 4 · 待建 9**

## 已建

- `适配器.js` —— runtime adapter：一份契约（工单+上下文包+权限声明 进，证据包 出），逐家 harness 一个适配器把契约映射到它自己的运行时。适配器要薄；厚的部分是契约与一致性判据。
- `适配器-claude.js` —— Claude Agent SDK 那家。有 hooks.PreToolUse，写闸能做成硬闸。resume 会话档续接。
- `契约一致性.js` —— 每家适配器必须过的同一套判据：同一张夹具单，各家交回的证据包形状一致、机判初检结论一致。契约改一个字段，五家全红——把「五处要记得同步」变成「五处会自己红」。
- `装配器.js` —— 一状态一会话的上下文包。首版装三样：这张单、进项文件的内容（不是路径，执行者不找）、协议职责权限节；人格语气不进执行卷；交付段按性质写死「不许自判做完、不许改状态」。历史会话与记忆条目等 领域/记忆 建了再接，现在不假装有。

## 待建

- **取单器** —— 按拍取单、派单、认领。
- **会话** —— Claude Agent SDK 接法：一席一模型、一席一上下文包、会话续接。
- **引擎** —— Unity 通道。外部命令方式调，不 require。要带编辑器租约——白天人在用同一个工程时抢锁是现成的暴露面。
- **巡检** —— 看门狗与后台循环。每一条都要能说出「它坏了会怎样」。
- **评审台** —— 异厂评审：各厂领一份立场卷、互不可见、独立出意见。两厂撞到同一落点是最强的信号。
- **情报** —— 抓源、去重、打分、入库。源挂了要说是哪个源挂了、连败几次，不许出一份空日报当正常。
- **适配器-codex** —— codex exec 那家。有 PreToolUse（Bash/apply_patch，exit 2 或 deny 实跑拦下）+ .rules 命令白名单，写闸能硬。本机 Windows 无头沙箱不可用、MCP 工具绕过沙箱已实证——写闸放 hook 层不放沙箱层。细节见 docs/harness四家对照。
- **适配器-hermes** —— Hermes Agent（NousResearch v0.21.0，MIT，Python）——是 harness 不是模型。三层 pre_tool_call、写路径硬拒、SQLite+FTS5 中文检索，兼知识库管理员候选。细节见对照表。
- **适配器-dsh** —— DeepSeek harness（0.1.2-alpha）。headless 只走 argv 无 stdin、无 usage、会话 zstd 不可直读、resume 只有 ACP、明写会破坏性变更。四家最弱，最后接。细节见对照表。
