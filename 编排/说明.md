## 待建

- **取单器** —— 按拍取单、派单、认领。
- **会话** —— Claude Agent SDK 接法：一席一模型、一席一上下文包、会话续接。
- **装配器** —— 上下文包 = 可达目录 + 本席历史会话 + 指定记忆条目。记忆检索是已知缺口，先落前两样。
- **引擎** —— Unity 通道。外部命令方式调，不 require。要带编辑器租约——白天人在用同一个工程时抢锁是现成的暴露面。
- **巡检** —— 看门狗与后台循环。每一条都要能说出「它坏了会怎样」。
- **评审台** —— 异厂评审：各厂领一份立场卷、互不可见、独立出意见。两厂撞到同一落点是最强的信号。
- **情报** —— 抓源、去重、打分、入库。源挂了要说是哪个源挂了、连败几次，不许出一份空日报当正常。
- **适配器** —— runtime adapter：一份契约（工单+上下文包+权限声明 进，证据包 出），逐家 harness 一个适配器把契约映射到它自己的运行时。适配器要薄；厚的部分是契约与一致性判据。
- **适配器-claude** —— Claude Agent SDK 那家。有 hooks.PreToolUse，写闸能做成硬闸。resume 会话档续接。
- **适配器-codex** —— codex exec 那家。必须 --dangerously-bypass-approvals-and-sandbox 否则弹窗卡死（坑档案）；**没有 pre-tool 钩子，写闸只能事后 diff 审计**。
- **适配器-hermes** —— Hermes 那家。接口待查。兼作知识库管理员候选（制作人 09-03 提的）。
- **适配器-dsh** —— DeepSeek harness 那家。MIT，347k 行，开发者预览、明写会破坏性变更——适配器会跟着它 churn，要有版本钉。
- **契约一致性** —— 每家适配器必须过的同一套判据：同一张夹具单，各家交回的证据包形状一致、机判初检结论一致。契约改一个字段，五家全红——把「五处要记得同步」变成「五处会自己红」。
