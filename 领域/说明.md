# 领域

工单生命周期、状态机、闸、席位、权限、额度。纯函数为主，不碰 fs、不发请求——这是变异台打得动、判据跑得快的前提。

- **可依赖**：内核
- **禁**：fs · http · child_process
- **已建 5 · 待建 7**

## 已建

- `状态机.js` —— 工单十三态与转移边；产出类型由性质推；要不要人判（产出/职能类别/保留）；闸结果一道一条履历，要凭查本轮履历。状态全集与大态分组唯一定义在这里，不许第二份。
- `单型.js` —— 读 docs/单型/ 五份 schema，做派前拆单校验：字段与默认、归属存在、性质在职能可接性质里、进项按签名齐且不多、末单规则（收口时）、散单特性唯一；剥(对象,角色) 按谁写过滤。纯函数；执行后那一侧归 领域/校验。
- `协议.js` —— 协议文档：按 docs/协议/schema.json 校验两层字段（职责权限 / 人格语气），从职责权限层导出权限声明给 领域/权限 求交，人格层给对话会话拼提示词。被研发环与智能体环两处读，所以单独成模块。
- `权限.js` —— 席位声明默认权限，工单可收紧不可放宽。求交结果编译一次、冻结、带哈希；落盘不在这儿（执行卷随进方与证据包走，编排层落）。 **它同时是多 harness 适配器的进方契约**——权限声明要能翻译成各家自己的放行表；翻不过去的家，写闸退化成事后审计，要明标。
- `校验.js` —— 机判初检，闸序列第一道：验包、回执非空、新建/修复/装配必须有改动、调研必须出 .md、改动不越执行卷（hook 拦过一次，这里事后兜底）、执行正常结束。纯函数零 token。判不了的显式列进待人判，不装作验过。逐条对验收标准等 docs/单型 的验收块落了再接。
