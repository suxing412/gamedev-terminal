# 接口

HTTP 路由、SSE、参数校验、形状转换。不含业务判断；路由一律走注册表，业务代码里不许出现 app.get/app.post。

- **禁**：（无）

## 已建

- `注册表.js` —— 唯一的路由注册函数：重复的 method+path 启动时直接 throw（旧仓两系统合并 5 条撞名，输的那边前端永远空白不报错）。分发：解析 URL 与 JSON 体、找路由、调处理器、统一出 JSON；404/500 也是 JSON；静态兜底给 web/。
- `app.js` —— 版本、健康、脉搏、视图表、路由表。视图表从正本的系统表生成（每系统一格：状态、这一圈、人在哪介入、凭什么算闭上了、靠及各自建没建），页签不手写。一个进程、Node 自带 http、不上 express。
- `prod.js` —— 生产：board 一屏（甘特条/人闸队列/按格计数/空转/树/坏文件）、工单库、一张单；收草稿成单、审批、记人闸能完成就完成、拍一次（跑真 harness 与深检站）。池每次从数据区现读，不养第二份事实。
